## git steps (inital one time setup )
1. > git init
2. > git remote add origin <git_url>
    eg: git remote add origin https://github.com/sagartmg2/chaitra-2082

    (optional) 
    > git remote -v


### git markings
U - untracked files // previously not synced to git
A - new untracked files added
M - modified files


### git commands ( daily use )
1. git status ( optional )
2. git add .  
    or 
    git add <file_name>
3. git commit -m "html-css & js init"
4. git push origin <branch_name>
   eg: git push origin master
